Aplicația desktop este structurată pe 3 niveluri independente:
1. **Nivelul de Prezentare (UI):** Interfața grafică (Dashboard, Catalog cărți cu căutare/filtrare, Ferestre modale pentru adăugare carte și împrumut/retur).
2. **Nivelul Logicii Aplicației (BLL):** Validarea datelor, verificarea disponibilității cărților la împrumut și calculul statisticilor.
3. **Stratul de Date (DAL):** Stocarea și interogarea entităților (Cărți, Cititori, Împrumuturi).
